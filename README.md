# SafarSetu

Safar Setu is a smart tourism platform that simplifies trip planning by bringing destinations, stays, transport, weather, budget-based recommendations, travel packages, local businesses, maps, and emergency assistance together in one platform.

## Features

- Tourist and local business accounts
- Budget-aware trip planning and recommendations
- Destination places, stays, transport, and weather information
- Business listings and travel packages
- Google Maps links and emergency service information
- SQLite database with seed data support

## Setup

1. Create and activate a Python virtual environment.
2. Install the dependencies:

   ```bash
   pip install -r requirement.txt
   ```

3. Copy `.env.example` to `.env` and set your own values.
4. Run the application:

   ```bash
   python app.py
   ```

The application starts at `http://127.0.0.1:5000/`.

## Configuration

`SECRET_KEY` and `WEATHER_API_KEY` are loaded from environment variables.
